  119: =head1 DESCRIPTION
  120: 
  121: Scans free-text military service notes from genealogy records and returns
  122: the name of the military branch mentioned.  Returns C<'military'> (localised)
  123: when no specific branch is recognised.
  124: 
  125: Designed to replace the C<service()> helper in the C<gedcom> and C<ged2site>
  126: distributions, which contain duplicate implementations of the same logic.
  127: 
  128: Detection patterns cover British, US and Commonwealth branches.  The returned
  129: string is localised to the system locale, which is detected from the
  130: environment at construction time.
  131:
